# 1复数与复变函数
## 1.1复数基础
1. $z = x + iy$
有实部$Re(z) = x$,虚部$Im(z) = y$
2. 复数的四则运算
### 复数的表示
1. 复数在复平面中以向量表示
2. 模$|z|=|\overline z| = r = \sqrt {x^2 +y^2}$
3. 辐角$Arg z$
辐角$Arg z = \theta$表示复数在复平面中与x轴正方向的夹角
任意的z都有无数个辐角
将$-\pi < \theta _0 < \pi$的$\theta _0$称为主值
记作$arg z = \theta _0$, $\tan {\theta _0} = {y\over x}$
