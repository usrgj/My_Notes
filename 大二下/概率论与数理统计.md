# 第一章 随机事件与概率

## 第一节 随机事件及运算

1. 在一定条件下必然发生，称为**确定性现象**。  
2. 结果不确定的现象，称为**随机现象**。  
3. 随机现象在大量重复试验中呈现规律，称为**统计规律性**。  
4. 随机试验（简称试验）  
   观察的过程叫**随机试验**。  
5. 试验的特点：  
   ① 相同条件下试验可以重复进行；  
   ② 每次试验的结果不止一种，试验前明确所有结果；  
   ③ 每次试验的结果无法预知。  

6. 随机试验的一切可能结果组成的集合称为**样本空间**，记作$\Omega = \{\omega\}$。样本空间可以是有限集、可数集、一个区间

7. 样本点  
   每次可能出现的一个结果称为**样本点**，记作$\omega$。  

8. 随机事件  
   一次试验中可能出现，也可能不出现的一类结果，称为**随机事件**，简称事件，用 A、B、C、D… 表示。  
   随机事件是样本空间的子集。  

9. 发生  
   当$\omega \in A$，则称事件A发生了，否则称事件A没有发生。  

10. 基本事件  
    仅含一个样本点的随机事件称为**基本事件**。  

11. 必然事件  
    每次试验一定发生的事件称为**必然事件**，记为$\Omega$是必然事件。  

12. 不可能事件  
    每次试验一定不发生的事件称为**不可能事件**，$\varnothing$是不可能事件。

13. 随机事件间的关系
(1) 包含  
A 发生则 B 必然发生，则 A 包含于 B（B 包含 A），  
记作$A \subset B$（或$B \supset A$）
(2) 相等  
A 发生则 B 必然发生，且 B 发生则 A 必然发生，则$A = B$
(3) 互不相容（互斥）  
A 和 B 不可能同时发生，$A \cap B = \varnothing$

14. 事件间的运算
(1) 并  
A 和 B 至少有一个发生，称 A 与 B 的并事件发生，记作$A \cup B$
(2) 交  
A 和 B 同时发生，称交事件发生，记作$A \cap B$
(3) 差  
A 发生且 B 不发生，称差事件发生，记作$A - B = A \cap \overline{B}$
(4) 对立事件  
事件$\Omega - A$称为 A 的对立事件（补事件），记作$\overline{A}$
对立一定互斥，互斥不一定对立

15. 运算性质
(1) 交换律  
$A \cup B = B \cup A$，  
$A \cap B = B \cap A$
(2) 结合律  
$(A \cup B) \cup C = A \cup (B \cup C)$，  
$(A \cap B) \cap C = A \cap (B \cap C)$
(3) 分配律  
$(A \cup B) \cap C = (A \cap C) \cup (B \cap C)$
$(A \cap B) \cup C = (A \cup C) \cap (B \cup C)$
(4) 对偶律（德摩根律,与逻辑运算中的相同）  
$\overline{A \cup B} = \overline{A} \cap \overline{B}$，  
$\overline{A \cap B} = \overline{A} \cup \overline{B}$
