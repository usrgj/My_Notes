电视
# ADB
> 首先在电视上打开adb调试，与电脑连接在同一局域网

## 连接
```bash
adb connect <tv ip>:5555 # 默认端口为5555  电视可能提示确认连接

adb disconnect # 不跟参数则断开全部设备 参数为<ip>:5555

adb devices # 列出已经连接的设备
```

## 安装软件
```bash
adb install <path to apk on pc>
```

## 文件
```bash
# 推送
adb push <origin file/dir on pc> <target dir on tv>
# /sdcard/相当与可写目录，主目录
adb push /path/to/local/*.txt /sdcard/Download/
# 用.表示推送终端路径下所有内容
adb push . /sdcard/Music/ 
#--sync 参数会跳过已存在且相同的文件，提高效率
adb push --sync . /sdcard/目标目录/

#拉取
adb pull <origin file/dir on tv> <target dir on pc> # 第二个参数为空时默认当前终端路径

```

## shell
```bash
adb shell <各种shell命令>

#获取电视上安装的应用列表
adb shell pm list packages
#找到应用的入口Activity（主界面
adb shell dumpsys package <包名> | grep "MAIN"
#启动应用的主界面
adb shell am start -n <包名>/<Activity名>
#强制停止目标应用
adb shell am force-stop <包名>
```

# Scrcpy
> 适用于安卓设备的屏幕镜像和远程控制

## 安装
```bash
sudo apt install scrcpy
```

## 连接
```bash
# 确保adb已经连接后
scrcpy --tcpip=192.168.1.10:5555 --encoder='OMX.google.h264.encoder' --max-size=1024 --max-fps=24

--max-size 1024 分辨率，低分辨率提升流畅度


```

## http
```bash
#默认共享当前终端所在目录
python -m http.server 8888
#查看电脑ip
hostname -I

#通过 ADB 命令调用 VLC 播放网络文件
adb shell am start -n org.videolan.vlc/org.videolan.vlc.gui.video.VideoPlayerActivity -a android.intent.action.VIEW -d "http://<pc ip>:8888/<video.mp4>"
```

## smb
### 安装
```bash
sudo apt update
sudo apt install samba
```

### 配置
```bash
sudo gedit /etc/samba/smb.conf
```
写入下面的内容，不支持行内注释
```ini
[Media]
path = /home/你的用户名/to/your/share/dir
browseable = yes
read only = no
guest ok = no
create mask = 0777
directory mask = 0777
```
```bash
#设置用户权限
sudo smbpasswd -a 你的用户名
#启动smb服务
sudo systemctl restart smbd
#验证服务状态，正常为Active: active (running)
sudo systemctl status smbd

#权限不足时确保权限开放
chmod -R 777 /home/你的用户名/your/dir
```

无法访问共享目录时
```bash
#仅允许 Samba 用户访问
sudo chown -R gj:gj /home/gj/smb  # 将目录所有者设为你的用户
sudo chmod 775 /home/gj/smb       # 允许所有者及同组用户读写

#改 Samba 配置
sudo gedit /etc/samba/smb.conf
```
写入
```ini
[Media]
path = /home/gj/smb
browseable = yes
read only = no
guest ok = no
create mask = 0777
directory mask = 0775
valid users =gj
force user =gj

#注解
[smb] #媒体名称
path = /home/gj/smb #共享路径
browseable = yes
read only = no
guest ok = no                # 禁止匿名访问
valid users = gj             # 允许你的用户访问
force user = gj              # 强制以你的用户身份访问文件
create mask = 0664           # 文件权限
directory mask = 0775        # 目录权限
```


```bash
#重启
sudo systemctl restart smbd
sudo systemctl status smbd   # 确认状态为 active (running)
```
